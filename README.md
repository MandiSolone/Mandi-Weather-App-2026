# Weather App (JavaScript + AccuWeather API)
A simple weather application built with vanilla JavaScript, HTML, and CSS.  
This project fetches real-time weather data using the AccuWeather API and demonstrates asynchronous JavaScript, API integration, and DOM manipulation. This uses a 2 step API integration first retrieving a location key, then fetching current conditions.

---

## Features 
- Search weather by city name
- Fetch location key using AccuWeather API
- Display current weather data
- Basic error handling for invalid cities
- Display a Temp Unit Toggle
- Simple UI built with HTML/CSS

### How to Download & Run This Project 

You can run this project locally by cloning it from GitHub.

1. Clone the repository. git clone https://github.com/MandiSolone/Mandi-Weather-App-2026-.git
2. Make sure you have a valid API key from AccuWeather (developer.accuweather.com). Replace the "YOUR_API_KEY" placeholder in app.js with your actual key from AccuWeather.
3. Go to the project folder and double-click or open index.html
